# mtpx

A command-line file manager for MTP devices, with a terminal UI. Built for pulling
files off, pushing files onto, and clearing out Garmin watches over USB, but works
with any MTP device.

Status: early development.

## Requirements

`mtpx` talks to devices through [libmtp](https://libmtp.sourceforge.net/):

- macOS: `brew install libmtp`
- Debian/Ubuntu: `apt install libmtp-runtime`
